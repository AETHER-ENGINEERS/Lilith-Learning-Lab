Free courses for the offline Lilith Learning Lab app: theory, animated lectures, concept maps, quizzes and hands-on Python labs. Search the catalog, read a course outline, then download it, or use the web app right in your browser.

How to use a course

  1. Install the Lilith Learning Lab app on Android.
  2. Open Library > Browse online and tap Get on a course, or download a course file here and use Import file.
  3. Teacher then gives you animated lectures, concept maps, quizzes, labs and a final exam, all offline.

Course files are plain JSON (format: "lilith-course"). The source, the app and the build scripts are in the GitHub repository.

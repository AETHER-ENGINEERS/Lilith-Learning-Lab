The user port gives you eight pins, PB0 to PB7, on CIA 2 port B ($DD01). Each pin is an input or an output depending on its bit in the data direction register DDR ($DD03). Set DDR to $0F (low four pins out, high four in), write $05 to the port, then flip two of the input switches.
DDR $DD03 (1 = output)
Output register $DD01 (what you write)
Outside world on each pin (switches you wire to inputs)
